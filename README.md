
# E-Commerce Admin Panel

A web-based administration panel for managing an e-commerce application. Built with React and Vite, with API communication, client-side routing, cookie management, and user notifications.

## Live Demo

[View E-Commerce Admin Panel](https://e-commerce-panel.vercel.app/)

## Tech Stack

- **React 18** — Component-based user interface
- **Vite** — Development server and build tool
- **React Router** — Client-side navigation
- **Axios** — HTTP requests and API communication
- **js-cookie** — Cookie management
- **React Toastify** — Toast notifications
- **Tailwind CSS** — Utility-first styling
- **ESLint** — Code quality and linting

## Features

- Admin-focused interface for e-commerce operations
- Client-side navigation with React Router
- API integration using Axios
- Cookie management
- User feedback through toast notifications
- Responsive interface styling with Tailwind CSS

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone <your-repository-url>
   ```

2. Navigate into the project directory:

   ```bash
   cd port-app
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Configure any required environment variables for your backend API.

5. Start the development server:

   ```bash
   npm run dev
   ```

6. Open the local URL displayed in your terminal.

## Available Scripts

| Command | Description |
|---|---|
| `npm run dev` | Starts the development server |
| `npm run build` | Builds the application for production |
| `npm run preview` | Previews the production build locally |
| `npm run lint` | Runs ESLint checks |
